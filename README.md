# ICFEC 2026

Official website for the **10th IEEE International Conference on Fog and Edge Computing (ICFEC 2026)**.

🔗 https://icfec2026.hanyang.ac.kr

## Tech Stack

- [Next.js](https://nextjs.org/) 15 (App Router)
- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/) 5
- [Tailwind CSS](https://tailwindcss.com/) 4

## Getting Started

```bash
npm install
npm run dev
```

Development server runs at `http://localhost:3001`.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start development server (port 3001) |
| `npm run build` | Production build |
| `npm start` | Start production server (port 8001) |
| `npm run lint` | Run ESLint |

## Project Structure

```
app/            # Next.js App Router (layout, page, styles)
components/     # UI components (Hero, Header, Footer, etc.)
constants/      # Shared constants
data/           # Conference data (committees, topics, papers, etc.)
public/         # Static assets (images, favicon)
utils/          # Utility functions
```
